# Blue Aluminum

**Aluminum for the Blue Economy.**

BlueAluminum.com is an independent category reference for aluminum products, systems, and value chains serving ocean-linked economic activity. It is not a producer, certification, or environmental claim.

## Public architecture

- `/` — category thesis
- `/definition/` — definition and admission test
- `/sectors/` — seven-sector application map
- `/material-system/` — lifecycle and decision layers
- `/evidence/` — evidence rules and source register
- `/category-map/` — classification matrix
- `/about/` — mandate, independence, and acquisition posture

Static, dependency-free, GitHub Pages-ready.
